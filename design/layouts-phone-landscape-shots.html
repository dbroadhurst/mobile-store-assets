Container styles

solid-panel rounded rect, ~0.78 alpha — hero, key headlines.
soft-band full-width band with feathered edge — captions, banners.
chip small filled pill — badges, feature claims, callouts.

What changes for landscape

Wide canvases unlock side-by-side composition that fails in portrait: text-left/phone-right, triple-phone rows, horizontal stat strips. The 2:1 aspect means text columns get genuine breathing room — no more 130 px columns.

Phone & content

Source-orientation drives everything. Landscape source screenshot → landscape phone frame + landscape canvas. No rotation. The plugin picks this layout family when the developer's app screens are landscape; for portrait apps it uses the portrait-shots family instead.

Copy budget

Headlines aim for ≤ 7 words (Adapty), benefit-led not feature-led (Apptweak). Landscape's extra horizontal room tempts longer copy — resist it. Decisions still happen in 17–50 ms.

Same gates

All four rules carry from portrait: WCAG AA contrast via computed-alpha scrims, merge-close-zones, auto-remediation retry on gate failure, and safe-area fit-test per text run.

Story arc — landscape (max 3 slots)

iOS caps landscape screenshots at 3 per device class, so the arc compresses. If you're publishing landscape in addition to portrait, the landscape set is usually a short Value → Flow → Trust sequence aimed at games / media / kids apps. For utility apps, landscape is rare — skip it.

The 25% zoom test — what users see in search

iOS shows landscape screenshots at roughly 160 × 75 in search results — about a quarter of authored size. The thumbnails below are the same SVGs as the full mockups, scaled to that target.

LL-01
Landscape Hero
Slot 1 · Value

Solid panel on the left half carries the brand + benefit headline + chips; landscape phone fills the right half showing the app's actual landscape UI. The 2:1 canvas finally makes a real text-left / phone-right composition work — both sides get full breathing room, and the phone matches the source screenshot's orientation.

  • Containers: solid-panel left (merged icon + headline + subhead) · chip eyebrow + 3 feature pills
  • Roles: badge · headline (3 lines, accent on last) · subheadline · 3 chips
  • Use case: Slot 1 Value · the workhorse landscape opener for portrait apps
LL-02
Landscape Caption
Slot 2 · Flow

Top soft-band carries a verb-led caption ("Three taps to track every habit"); the landscape phone fills the area below. Adapty's "text in upper half" rule applies even more in landscape — the wide bottom area is where the eye lands second.

  • Containers: soft-band top (merged headline + subhead, feathered bottom edge)
  • Roles: headline (1 line) · subheadline (1 line)
  • Use case: Slot 2 Flow · the workhorse landscape default
