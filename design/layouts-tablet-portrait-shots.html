Container styles

solid-panel rounded rect, ~0.78 alpha — hero, key headlines.
soft-band full-width band with feathered edge — captions, banners.
chip small filled pill — badges, feature claims, callouts.

What changes for tablet portrait

The wider 3:4 aspect unlocks side-by-side composition (tablet + text column) that's cramped at phone-portrait 1:2.17. Headlines can be larger; chips and stat tiles get real width.

Copy budget

Same rules as the phone set — ≤ 7 words per headline (Adapty), benefit-led not feature-led (Apptweak). Don't let the extra room talk you into longer copy.

Same gates

All four rules carry: WCAG AA contrast via computed-alpha scrims, merge-close-zones, auto-remediation retry on gate failure, and safe-area fit-test per text run.

Story arc — tablet portrait (up to 10 slots)

iOS allows up to 10 portrait screenshots per iPad device class (12.9" and 13"). Most apps publish 3–5 tablet screenshots in practice. The arc below is the recommended sequencing if you go long; truncate to your first 3 if you only have time for the high-impact slots.

The 25% zoom test — what users see in search

iPad search results show tablet screenshots at roughly 120 × 160 — about a quarter of authored size. The thumbnails below are the same SVGs scaled to that target.

TP-01
Hero Type
Slot 1 · Value  /  Slot 10 · CTA

Brand icon → big stacked benefit headline → subhead → row of honest feature chips. No tablet shown — the screenshot promises the outcome, not the UI. Tablet portrait's extra room means headline can run 42pt at thumbnail size without crowding.

  • Containers: solid-panel merged (headline + subhead + chips inside)
  • Roles: headline (3 lines, accent on last) · subheadline (≤ 2 lines) · 3 chips
  • Use case: Slot 1 Value · Slot 10 CTA · the brand frame
TP-02
Caption Band
Slot 2 · Flow  /  Slot 6 · Feature

Portrait tablet hero in the top 70%, full-width soft-band caption at the bottom. Tablet's wider aspect means the app UI inside the tablet shows more cards/rows at once — more substance per screenshot than phone allows.

  • Containers: soft-band bottom (feathered top edge)
  • Roles: headline (≤ 2 lines) · subheadline (1 line)
  • Use case: Slot 2 Flow · the workhorse tablet portrait default
TP-03
Editorial Split
Slot 4 · Feature

Tablet on the right, magazine-style dark panel on the lower-left with an accent rule, step chip + headline + body. Tablet portrait's 3:4 aspect finally lets a real text-column-plus-device composition breathe — the panel's 220 px width is enough for 34pt headlines.

  • Containers: solid-panel lower-left (merged step + headline + body) + accent rule
  • Roles: badge (step) · headline (≤ 3 lines, accent on last) · body (≤ 2 lines)
  • Use case: Slot 4 Feature · step-by-step sequences
TP-04
Bento
Slot 5 · Feature  /  Slot 3 · Trust

Vertical bento: headline strip top, full-width portrait tablet hero in the middle, two equal stat tiles at the bottom. The 3:4 aspect gives stat tiles a real 208 px width — three or four lines of supporting copy fit cleanly.

  • Containers: solid-panel headline · tablet card · 2 × solid-panel stat tiles (one in accent)
  • Roles: headline (≤ 2 lines) · 2 × (label + stat + caption)
  • Use case: Slot 3 Trust · Slot 5 Feature · stat-driven proof
TP-05
Feature Stack
Slot 3 · Trust  /  Slot 9 · Recap

No tablet — the screenshot itself is the feature list. Icon + headline at top, four full-width numbered rows in the body (the fourth in accent), credibility chip footer. Same idea as the phone Feature Stack but with 400 px-wide rows that fit fuller copy without trimming.

  • Containers: solid-panel title · 4 × solid-panel rows (last in accent) · chip footer
  • Roles: headline · 4 × (badge + label + body) · footer caption
  • Use case: Slot 3 Trust · Slot 9 Recap · "what's inside"
TP-06
Headline Masthead
Slot 1 alt · Value  /  Slot 9 · Trust

Solid masthead panel up top with an eyebrow chip + 3-line benefit headline; tablet occupies the lower 60%. Same intent as the phone Headline Masthead but with tablet portrait's extra room — headline can run at 34pt without crowding.

  • Containers: solid-panel top + chip eyebrow
  • Roles: badge/eyebrow · headline (≤ 3 lines, accent on last)
  • Use case: Slot 1 alt Value · "What's new" framing
TP-07
Dual Tablet
Slot 6 · Feature

Two portrait tablets fanned with opposing tilts — front (light) overlapping back (dark) showing the same app in both themes. Top headline panel anchors the composition. Use when the feature is a theming or A/B mode story.

  • Containers: solid-panel top (merged headline + subhead) · device frames carry the rest
  • Roles: headline (≤ 2 lines) · subheadline
  • Use case: Slot 6 Feature · light/dark · A/B mode
TP-08
Tilted Card
Slot 7 · Feature (premium)

Tablet presented inside a slight-tilt floating card (drop shadow + rotation), with a solid headline panel anchored at the bottom. Use for the most brand-forward feature; best when the tablet's screen itself is visually strong.

  • Containers: tablet in card · solid-panel bottom (merged headline + subhead)
  • Roles: headline (≤ 2 lines, accent on line 2) · subheadline (≤ 1 line)
  • Use case: Slot 7 Feature · brand-forward / device-as-hero shots
