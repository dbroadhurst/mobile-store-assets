Container styles

solid-panel rounded rect, ~0.78 alpha — hero, key headlines.
soft-band full-width band with feathered edge — captions, banners.
chip small filled pill — badges, feature claims, callouts.

What changes for tablet landscape

4:3 aspect with ~640 px of width unlocks three-column compositions (sidebar + tablet + sidebar) that don't work at any phone aspect. Tablets themselves often run multi-pane apps — the marketing mirrors that visual language.

Phone & content

Source-orientation drives everything. Landscape source screenshot → landscape tablet frame + landscape canvas. No rotation. Same rule as every other file in this system.

Same gates

All four rules carry: WCAG AA contrast via computed-alpha scrims, merge-close-zones, auto-remediation retry on gate failure, and safe-area fit-test per text run.

Story arc — tablet landscape (compressed)

iOS allows up to 10 landscape tablet screenshots, but most apps publish 3–5 in practice. The arc below is sized for that reality: Value → Flow → Trust, with two feature beats and a CTA. If you publish only 3, take the first three.

The 25% zoom test — what users see in search

iPad search shows landscape screenshots at roughly 160 × 120 — about a quarter of authored size. The thumbnails below are the same SVGs scaled to that target.

TL-01
Hero Side
Slot 1 · Value

Solid panel on the left half (brand + headline + chips), landscape tablet on the right showing the app's actual multi-pane UI. The wide 4:3 canvas finally lets the tablet display its native sidebar-plus-content layout at recognisable size — text and tablet each get full breathing room.

  • Containers: solid-panel left (merged icon + headline + subhead) · chip eyebrow + 3 feature pills
  • Roles: badge · headline (3 lines, accent on last) · subheadline · 3 chips
  • Use case: Slot 1 Value · the workhorse landscape iPad opener

Text Hero
Slot 1 alt · Value

No tablet — pure benefit promise centred in the wide canvas, with an honest chip row underneath. Works as either the opening Value shot (brand-forward) or, for utility apps with only 1 landscape iPad slot, the entire set.
